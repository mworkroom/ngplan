# 2026-08-04 ngplan 개발 로그

## Work Summary - Phase 4 V3 2차 동결 전 실제 시작값 검증

베로니카 좌 시작값이 0에서 235로 정정된 사실이 기존 자동안과 수동안의 차이를 설명하는지 분리해서 확인했다. 정정값을 기존 회귀에 덮어쓰지 않고 별도 fixture로 만들었으며, Kelly의 900 근처 실적을 700과 다음 300 경계로 나누는 국소 후보가 안전한 개선인지 제한적으로 탐색했다.

## Work Completed - Phase 4 V3 2차 동결 전 실제 시작값 검증

- 베로니카 좌 시작값 0인 역사 fixture를 그대로 보존했다.
- 좌 시작값 235를 적용한 별도 fixture와 서로 다른 요청 fingerprint를 회귀 테스트에 고정했다.
- 정정 조건에서 승인 수동안은 총 23,510PV, 확인 수당 6,060,000원, 비루트 환산 79회로 다시 평가했다.
- 같은 조건의 Policy 11 V3는 총 23,500PV, 확인 수당 6,000,000원, 비루트 환산 78회이며 모든 비루트 기본 몫을 지키는 것을 확인했다.
- Kelly 경계 후보를 실제로 생성하고 검증해 Kelly 19회 후보가 존재하지만, 모두 다른 회원의 기본 몫을 훼손하고 비루트 합계를 78보다 높이지 못하는 사실을 회귀로 고정했다.
- 여러 손상 회원을 다시 보정하는 제한된 후속 탐색도 수행했지만 비루트 합계 78을 넘는 후보는 찾지 못했다.

## Decisions - Phase 4 V3 2차 동결 전 실제 시작값 검증

- 시작값 정정 효과와 알고리즘 개선 효과를 섞지 않기 위해 0과 235 조건을 별도 fixture로 유지한다.
- 베로니카 시작값 235는 수동안과 V3를 모두 한 회씩 올릴 뿐 Kelly의 한 회 차이를 설명하지 않는다.
- Kelly만 19회로 만드는 국소 이동이 박진숙·김길주 등의 기본 몫을 깎으므로 production 후보 생성기에 추가하지 않는다.
- 남은 한 회를 찾으려면 여러 회원·여러 날짜를 동시에 다시 짜는 큰 탐색이 필요하다. 현재 수동 계획표가 운영 가능하고 추가 기준 확인이 당분간 어려운 상황에서는 Policy 11을 2차 동결하는 것이 안전하다.
