# 2026-08-02 ngplan 개발 로그

## Work Summary

계획표의 4단 헤더가 페이지를 세로로 내릴 때 사라지는 문제를 다시 확인하고, 표 안에서 헤더가 계속 보이도록 스크롤 기준을 정리했습니다.

## Work Completed

- `manual-plan-scroll`을 가로 전용 스크롤에서 가로·세로 스크롤 영역으로 변경했습니다.
- 계획표 높이를 화면의 70% 또는 720px 이내로 제한해 날짜가 많아도 표 안에서 세로로 이동할 수 있게 했습니다.
- 표 안쪽으로 스크롤할 때 `ID → 목표값 → 잔액 → 날짜` 4단 헤더가 상단에 고정되도록 기존 sticky 헤더 규칙과 연결했습니다.
- 내부 스크롤을 확인하는 임시 브라우저 fixture로 실제 위치 변화를 검증한 뒤 fixture는 삭제했습니다.
- 계획표 컴포넌트 테스트 24개, 타입 검사, 프로덕션 빌드를 통과했습니다.

## Decisions

기존 표는 가로 스크롤 상자 안에 있었지만 세로 스크롤 기준이 없어 페이지 스크롤 시 sticky 헤더가 함께 이동했습니다. 별도 헤더 복제와 가로 위치 동기화보다 표 자체에 세로 스크롤을 부여하는 방식이 구조와 접근성 변경을 최소화하면서 현재 화면에서 바로 이해하기 쉬운 해결책이라고 판단했습니다.

## Current Status

로컬 fixture에서 표 안쪽 `scrollTop`을 변경해도 첫 번째 헤더가 표 상단에 유지되는 것을 확인했습니다. 계획표 실제 화면은 로그인 뒤에 있어 브라우저에서 회원 데이터가 필요한 표까지는 접근하지 못했지만, 계획표 전용 테스트·타입 검사·빌드는 모두 통과했습니다.

## Next Steps

로그인 후 실제 계획표에서 날짜가 많은 자료를 열고, 표 안쪽 세로 스크롤과 가로 스크롤을 함께 사용할 때 헤더와 첫 날짜 열이 기대한 위치에 남는지 한 번 더 확인합니다.

## Work Summary - 계획표 이미지 만들기

계획표를 휴대전화로 촬영하고 사람별 영역을 자르던 작업을 줄이기 위해, 시트에서 최대 5명을 골라 날짜와 해당 회원 열만 PNG 이미지로 만드는 기능을 추가했습니다.

## Work Completed - 계획표 이미지 만들기

- 계획표 헤더의 동작 순서를 `이미지 만들기 → 설정으로 돌아가기 → 전체 목록으로`로 배치했습니다.
- 일반 창 너비에서도 세 버튼이 화면 오른쪽 밖으로 밀리지 않도록 계획표 헤더 너비를 보정했습니다.
- 큰 체크 항목으로 회원을 1명부터 5명까지 고르는 선택창을 추가했습니다.
- 회원을 누른 순서와 관계없이 실제 계획표에 보이는 순서로 정렬해 이미지에 넣도록 했습니다.
- 맨 왼쪽 날짜 열과 선택한 회원별 `PVP·좌·우` 세 열, 저장된 계획 제목을 함께 출력하도록 했습니다.
- 현재 셀 값뿐 아니라 수당 발생 표시와 실제 차이 빨간 표시도 이미지에 남도록 처리했습니다.
- 생성한 이미지를 먼저 확인한 뒤 저장할 수 있게 했고, 파일 공유를 지원하는 기기에서는 `이미지 공유하기`도 표시하도록 했습니다.
- SVG를 Blob 주소로 읽을 때 캔버스 저장이 차단되는 실제 브라우저 오류를 데이터 주소 방식으로 해결했습니다.
- 이미지에 필요한 스타일만 복사하도록 최적화해 최대 5명 이미지 생성 시간을 실제 확인 화면 기준 약 1.8초로 줄였습니다.
- 이미지 선택 순서, 최대 5명 제한, PNG 생성과 실패 처리, 저장·공유, 헤더 버튼 순서 테스트를 추가했습니다.
- 기존 안내 문구 변경과 맞지 않던 앱 테스트 문구를 현재 화면 문구에 맞췄습니다.

## Decisions - 계획표 이미지 만들기

회원 이름마다 개별 버튼을 붙이지 않고 헤더에 이미지 작업의 시작점을 하나만 두기로 했습니다. 한 사람과 여러 사람을 같은 흐름에서 처리할 수 있고, 이름 열에 반복되는 버튼을 만들지 않아 계획표가 복잡해지지 않기 때문입니다. 출력 순서는 선택 순서가 아니라 시트 순서를 기준으로 고정해 전달 이미지가 원본 계획표와 항상 같은 방향으로 읽히게 했습니다. 최대 인원은 실제 사용 범위인 5명으로 제한했고, 5명 결과가 1828×1684px로 충분히 읽을 수 있는 것을 확인했습니다.

## Current Status - 계획표 이미지 만들기

로컬 실제 브라우저에서 `202608A 민경욱` 확인 자료를 열어 회원을 역순으로 선택한 뒤에도 `날짜 → 시트 순서의 회원`으로 출력되는 것을 확인했습니다. 최대 5명 선택 시 여섯 번째 항목이 비활성화되고, 1828×1684px PNG가 약 1.8초에 생성되는 것도 확인했습니다. 타입 검사, 전체 714개 테스트, 커버리지 기준, 프로덕션 빌드, 배포 파일 스모크 검사를 모두 통과했습니다.

## Next Steps - 계획표 이미지 만들기

- 실제 저장된 계획에서 회원 이름, 셀 값, 수당 표시, 빨간 표시가 기대한 모습으로 함께 나오는지 최종 사용 확인을 진행합니다.
- 회원 이름을 눌러 한 사람 이미지를 바로 만드는 단축 동작은 별도 후속 기능으로 검토합니다.
