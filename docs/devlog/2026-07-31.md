## Decisions - 회원별 좌·우 목표 1,500/2,500 선택

- 1,500은 2,500을 대체하는 전역 규칙이 아니라 회원별 선택값이다. 피라미드 단계나 PVP 목표와 연결하지 않는다.
- 새 기간은 이전 선택을 묵시적으로 이어받지 않고 항상 2,500에서 시작한다. 매 기간 사용자가 필요한 회원만 1,500으로 바꾸게 한다.
- 기존 자동 최적화 알고리즘은 2,500 전용으로 유지한다. 1,500 목표의 수당 5회 배치 권장은 추가 데이터가 모인 뒤 자동 알고리즘을 다시 설계할 때 반영한다.
- 기존 저장 데이터에 목표값이 없으면 당시 동작과 같은 2,500으로 이전한다. 파생 계산 결과와 오래된 자동 계산 진행 상태는 새 규칙으로 다시 만들도록 정리한다.
