# 2026-07-15 ngplan Development Log

## Work Summary

수동 계획표에서 회원 목표값 대신 실제 회원번호를 바로 확인하고, PVP를 포함한 세 시작값과 기간 누계를 한 화면에서 비교할 수 있도록 표의 머리글과 하단 요약 행을 개선했다.

## Work Completed

- 회원 이름 아래의 `목표 … PV` 문구를 `회원번호 …`로 교체했다. 회원번호가 비어 있으면 `회원번호 미입력`으로 표시한다.
- PVP·좌·우 열 머리글 아래에 각각 PVP 시작값, 좌 시작값, 우 시작값을 숫자로 표시하고 접근성 이름에도 어떤 시작값인지 명시했다.
- 표 맨 아래에 `이번 기간 총합` 행을 추가했다. 회원별 기간 신규 PVP, 기간 조직 좌 합계, 기간 조직 우 합계를 각 열에 표시한다.
- 하위 회원의 직접 실적이 상위 회원의 조직 좌·우에 반영되는 정본 계산 결과를 합계 행에 사용했다.
- 입력 오류로 계산이 막힌 동안에는 오래된 합계를 노출하지 않고 `—`를 표시한다.
- 회원 그룹의 좌·우·루트 색상과 3열 단위 경계선을 합계 행에도 적용했다.
- 로컬 브라우저에서 PVP 시작 33, 좌 시작 2,050인 회원으로 표를 열어 머리글과 하단 합계 행을 확인하고, 좁은 날짜 칸의 합계 문구가 글자 중간에서 갈라지지 않도록 단어 단위 줄바꿈을 적용했다.
- 표 헤더, 시작값, 합계 행과 상위 조직 전파 결과를 확인하는 회귀 테스트를 보강했다.
- 전체 테스트 39개 파일의 545개 테스트, 타입 검사와 production 빌드를 통과했다.

## Decisions

- 하단 합계의 PVP는 시작값을 포함한 평생 누적값이 아니라 이번 기간에 새로 입력된 PVP 합계로 표시한다. 시작값은 이미 머리글에서 별도로 확인할 수 있어 중복 합산을 피하기 위해서다.
- 좌·우 합계는 직접 입력칸만 더하지 않고 계산 엔진의 `rawLeftTotal`과 `rawRightTotal`을 사용한다. 그래야 하위 조직에서 올라온 실적까지 시트의 일별 좌·우 값과 동일하게 합산된다.
- 기존 PVP 목표는 계산 규칙으로 계속 유지하되, 긴 계획표에서 실사용자가 회원을 식별하는 데 더 필요한 회원번호를 머리글에 표시한다.

## Current Status

- 수동 계획표는 회원 이름, 회원번호, PVP·좌·우 열, 세 시작값 순서로 표시된다.
- 표 마지막 행에서 각 회원의 이번 기간 PVP·좌·우 총합을 확인할 수 있다.
- 관련 회귀 테스트와 전체 테스트, 타입 검사, production 빌드가 모두 통과했다.

## Next Steps

- 실제 회원 데이터와 긴 조직표에서 회원번호 및 하단 합계 행의 가독성을 확인한다.
