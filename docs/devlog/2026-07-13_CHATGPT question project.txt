자동 시뮬레이션 결과를 ChatGPT에 질문하는 기능 구상
배경

Phase 4 자동 시뮬레이션이 완성되면 앱이 먼저 계산된 계획을 제시하게 된다. 사용자는 결과를 보며 다음과 같은 질문을 하게 될 수 있다.

왜 이 회원의 이 날짜에 이 숫자가 들어갔는가?
왜 PVP 100이 다른 회원이 아니라 이 회원에게 배치되었는가?
이 값을 다른 날짜로 옮기면 어떤 결과가 달라지는가?
사람이 만든 계획과 자동 계획이 다른 이유는 무엇인가?
앱의 계산이 실제 규칙에 맞는가?

이 질문을 매번 엄마 → J님 → ChatGPT 순서로 전달하는 것은 비효율적이므로, 엄마가 자신의 ChatGPT 프로젝트에서 직접 질문할 수 있는 구조를 마련한다.

ChatGPT 프로젝트 구성

엄마의 ChatGPT 계정에 피라미드 앱 전용 프로젝트를 만들고 다음 자료를 넣는다.

현재 회사 계산 규칙을 정리한 md 파일
ChatGPT가 답변할 때 지켜야 할 Project Instructions

규칙 문서는 영어로 작성하되, Project Instructions에서 답변은 쉬운 한국어로 하도록 지정한다. qualification PVP, carry, reset, discarded excess 같은 용어의 의미가 번역 과정에서 달라지는 문제를 줄이기 위한 방식이다.

과거 규칙은 현재 계획의 판정 기준으로 사용하지 않는다.

초기 질문 방식

첫 테스트 단계에서는 앱 화면을 캡처해 ChatGPT에 올리고 질문한다.

예:

기경률의 7월 18일 PVP에 왜 100이 들어갔나요?
김경자에게 넣는 것과 어떤 차이가 있나요?

캡처에는 가능하면 다음 정보가 함께 보이도록 한다.

회원 이름
날짜
PVP·좌·우 값
전일 잔액
당일 하위 조직 실적
PVP 적용 전후 값
qualification PVP
커미션 단계
정산 후 carry/reset
관련 하위 회원과 상위 회원

한 셀만 잘라서 보여주면 전체 조직 효과를 판단하기 어렵기 때문에, 필요한 경우 여러 장을 함께 올린다.

캡처만으로 판단할 수 없을 때 ChatGPT는 화면에 없는 값을 추측하지 않고, 필요한 화면이나 숫자를 구체적으로 요청한다.

앱에 추가할 수 있는 질문용 복사 기능

반복되는 질문 유형이 확인되면 앱에 다음 기능을 추가할 수 있다.

셀 우클릭 메뉴
결과 상세 메뉴
ChatGPT 질문용으로 복사
이 숫자 설명용 정보 복사

사용자가 특정 셀을 선택하면 앱이 해당 숫자의 계산 맥락을 텍스트로 자동 생성한다.

예:

[자동 계획 질문]

회원: 기경률
날짜: 2026-07-18
궁금한 셀: PVP
표시된 값: 100

전일 잔액:
PVP 0 / 좌 0 / 우 0

당일 직접 입력:
PVP 100 / 좌 0 / 우 0

하위 조직에서 올라온 실적:
좌 600 / 우 700

PVP 적용 후:
좌 700 / 우 700

Qualification PVP:
300 이상

수당:
700 단계

정산 후 잔액:
PVP 0 / 좌 0 / 우 0

질문:
왜 PVP 100이 이 회원의 이 날짜에 배치되었나요?
다른 회원이나 날짜에 배치하면 어떤 차이가 생기나요?

엄마는 복사된 내용을 ChatGPT 프로젝트에 붙여 넣고, 원하는 질문만 덧붙인다.

설명에 포함하면 좋은 내용

ChatGPT는 결과를 설명할 때 다음 순서로 분석한다.

이 값이 당일 어떤 역할을 하는지
본인의 PVP 목표와 qualification에 어떤 영향을 주는지
당일 커미션과 carry/reset이 어떻게 달라지는지
하위 조직과 상위 회원에게 어떤 영향을 주는지
값을 제거하거나 다른 곳으로 옮겼을 때 무엇이 달라지는지

가능하면 다음 두 항목도 제공한다.

이 값이 하는 역할
이 값을 제거했을 때 달라지는 결과

단순 추측이 아니라 앱이 해당 값을 0으로 바꿔 다시 계산한 결과를 제공하면 설명의 정확도가 높아진다.

진행 순서
엄마의 ChatGPT 프로젝트에 계산 규칙 문서와 Project Instructions를 넣는다.
초기에는 화면 캡처와 간단한 질문으로 테스트한다.
엄마가 반복해서 묻는 질문 유형을 기록한다.
반복 패턴이 확인되면 앱에 질문용 정보 복사 기능을 추가한다.
이후 필요하면 특정 값 제거·이동 전후 비교 기능까지 확장한다.

핵심은 화면 캡처만 전달하는 것이 아니라, 앱이 계산에 사용한 맥락을 텍스트로 함께 제공하는 것이다. 캡처는 보조 자료이고, 질문용 계산 요약이 실제 설명의 기준이 된다.
