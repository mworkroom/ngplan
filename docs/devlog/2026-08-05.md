## Work Summary

계획표를 만드는 과정에서 내부 계산 방식이 화면에 직접 드러나지 않도록 안내 문구를 일상적인 표현으로 바꿨다.

## Work Completed

- 화면 제목을 `계획표 만드는 중`으로 변경했다.
- 진행 중인 내용을 사용할 수 있는 버튼을 `지금 내용으로 계획표 보기`로 변경했다.
- 준비된 계획표를 확인하는 버튼을 `완성된 계획표 보기`로 변경했다.
- 계획을 더 개선하는 중이라는 상태를 `계획표가 준비되었습니다. 조금 더 정리하고 있습니다.`로 변경했다.
- 관련 컴포넌트 및 화면 흐름 테스트의 기대 문구를 함께 수정했다.

## Decisions

- 사용자가 내부 계산 방식을 이해하지 않아도 다음 결과를 예측할 수 있도록 `자동`과 `계산` 대신 `계획표`를 중심으로 표현했다.
- 작업 중단 버튼은 현재까지 만든 내용이 사라지는 것으로 오해하지 않도록, 누르면 확인하게 되는 결과를 버튼 이름에 직접 적었다.

## Current Status

요청한 네 문구와 관련 테스트를 수정했다. 관련 컴포넌트 및 화면 흐름 테스트 19개, TypeScript 타입 검사, 프로덕션 빌드가 모두 통과했다. 빌드에는 기존의 청크 크기 안내가 남아 있지만 이번 문구 변경과 관련된 오류는 없다.
