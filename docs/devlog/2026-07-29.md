# 2026-07-29 ngplan Development Log

## Work Summary

계획 편집 화면에 정보와 버튼이 여러 층으로 겹쳐 보이던 문제를 줄이기 위해 상단 구조를 두 줄 중심으로 재정리했다. 시트 기간과 핵심 작업을 애터미 블루 헤더에 모으고, 조직도 도구와 입력 오류 이동 기능은 간결한 보조 줄로 통합했다.

## Work Completed

- 첫 줄을 애터미 블루 배경의 작업 헤더로 변경하고 현재 기간, `기간 변경`, `수동 플랜 만들기`, `자동 플랜 만들기`, `전체 목록으로`를 배치했다.
- 기간 및 프로젝트명 입력은 상시 노출하지 않고 `기간 변경` 대화상자에서 수정하도록 옮겼다.
- 편집 화면의 자동 저장 안내, 저장 상태, 로그인 사용자 정보, 로그아웃 버튼을 제거했다. 사용자 정보와 로그아웃은 전체 목록 화면에 유지했다.
- 조직도 보조 줄의 참여 인원 표시에서 테두리를 제거하고, 확대·축소 도구를 `− 100% + 처음 위치` 형태로 단순화했다.
- 기존의 큰 빨간 경고 막대를 없애고 `입력 확인 N건`과 `다음 문제`를 빨간 글자만으로 표시했다.
- 기존 회원 카드와 회원 입력창의 문구 및 UI는 변경하지 않았다.
- 변경된 화면 구조에 맞춰 UI 테스트를 갱신했다.

## Decisions

- 편집 화면의 시각적 기준점은 기간 제목이 있는 파란 헤더로 정했다. 저장과 계정 정보는 편집의 핵심 작업이 아니므로 상위 목록 화면에만 남겼다.
- 오류가 많은 조직에서도 문제를 순서대로 바로 수정할 수 있도록 오류 개수와 `다음 문제` 이동 기능은 유지하되, 경고 상자 대신 텍스트 강조만 사용했다.
- `처음 위치`는 조직도 배율을 100%로 되돌리고 가로 스크롤을 시작점으로 이동하는 동작으로 정의했다.

## Current Status

- TypeScript 타입 검사를 통과했다.
- 전체 Vitest 테스트 56개 파일, 651개 테스트가 모두 통과했다.
- Vite 프로덕션 빌드와 배포 산출물 smoke 검사를 통과했다.
- 빌드 시 기존과 같은 큰 JavaScript 청크 경고가 남아 있으나 이번 UI 변경의 동작에는 영향을 주지 않는다.

## Next Steps

- 회원 카드 및 오른쪽 입력 패널의 문구와 UI 개선은 이번 범위에서 제외했으며 별도 작업으로 진행한다.

## Work Summary - 전체 화면 헤더 통일

회원 정보 입력 화면에서 정한 애터미 블루 헤더를 전체 목록, 수동 계획표, 자동 계획표에도 동일하게 적용했다. 각 화면에 중복 노출되던 날짜, 저장 안내, 계정 정보와 설명 문구를 걷어내고 화면 제목과 핵심 이동 버튼만 남겼다.

## Work Completed - 전체 화면 헤더 통일

- 전체 목록 화면의 헤더를 애터미 블루 배경과 흰 글씨로 변경했다.
- 전체 목록의 H1을 `애터미 직급 계획표`로 정리하고 `저장된 계획` 문구와 로그인 계정 표시를 제거했다.
- 전체 목록 헤더 오른쪽에는 `새 계획 만들기`, `로그아웃`만 유지했다.
- 수동·자동 계획표 헤더 왼쪽에 각각 `수동 계획표`, `자동 계획표`와 시트 제목을 두 줄로 표시했다.
- 수동·자동 계획표 헤더 오른쪽에는 `설정으로 돌아가기`만 유지했다.
- 계획표의 날짜 범위, 자동 저장 안내, 입력 설명, 날짜·인원 요약을 제거했다.
- 큰 화면에서도 헤더 H1이 과도하게 커지지 않도록 작은 화면 기준인 `1.45rem`으로 고정했다.
- 기존 회원 카드와 회원 정보 입력창의 문구 및 UI는 변경하지 않았다.

## Decisions - 전체 화면 헤더 통일

- 각 화면의 구심점은 동일한 파란 헤더로 만들되, 화면별 성격과 시트 제목은 위계를 나눠 두 줄로 표시하기로 했다.
- 자동 저장과 로그인 계정은 해당 화면의 핵심 작업 정보가 아니므로 반복 노출하지 않기로 했다.
- 계획표 표 내부에서 페이지명을 다시 설명하지 않고 헤더에서 한 번만 명확히 보여 주도록 중복 제목과 설명을 제거했다.
