# 2026-07-16 ngplan Development Log

## Work Summary

로그인 후 사용하는 애터미 업무 화면 캡처를 기준으로, 기존 플래너의 기능과 정보 구조는 유지하면서 전체 UI를 사내 업무도구에 가까운 시각 언어로 정리했다. 둥근 카드와 그림자 중심의 일반적인 SaaS 분위기를 줄이고, 흰 배경·얇은 구획선·절제된 하늘색 강조·차콜색 실행 버튼을 중심으로 화면의 성격을 바꿨다.

## Work Completed

- 전역 테마의 배경, 본문색, 보조색, 구분선, 성공·오류색을 업무 화면에 맞게 조정했다.
- 공통 radius를 8px에서 2px로 낮추고 패널 그림자를 제거했다. 조직 카드의 별도 radius와 선택 그림자도 같은 원칙으로 정리했다.
- 화면 상단에 하늘색 기준선을 추가하고, 페이지 제목 아래에는 짙은 구분선을 배치해 애터미 업무 화면의 명확한 제목 위계를 반영했다.
- 주요 실행 버튼은 차콜색, 보조 버튼은 흰 배경과 회색 테두리로 구분했다. 하늘색은 안내선, 선택 상태, 포커스처럼 현재 맥락을 보여주는 데 사용했다.
- 패널 머리글, 입력 영역, 저장 안내, 조직도 배경을 그림자 대신 선과 여백으로 구획하도록 변경했다.
- 수동 계획표의 외곽 카드 표현을 줄이고, 표 헤더·날짜 열·좌우 조직·합계 행을 옅은 회색과 하늘색·보라색 계열로 정리했다.
- PVP·좌·우 셀 및 입력창 너비와 `작게`·`편안하게` 화면 크기별 너비 규칙은 수정하지 않았다.
- 로컬 브라우저에서 설정 화면, 회원 카드, 준비 완료 화면, 수동 계획표까지 직접 열어 스타일과 기존 흐름을 확인했다.
- production 빌드, 타입 검사, 전체 39개 테스트 파일의 545개 테스트를 통과했다.

## Decisions

- 참고 화면의 기능이나 화면 구성을 복제하지 않고, 현재 플래너에 필요한 시각 규칙만 적용했다. 아직 기능 추가가 진행 중이므로 DOM 구조를 크게 바꾸지 않는 편이 이후 작업과 회귀 위험을 줄이기 때문이다.
- radius를 완전히 제거하지 않고 2px를 공통값으로 유지했다. 입력창과 상태 영역의 경계를 식별할 수 있으면서도 둥근 SaaS 카드처럼 보이지 않게 하기 위한 결정이다.
- 주요 실행 버튼은 애터미 화면에서 검색 버튼이 맡는 역할처럼 차콜색으로 두고, 브랜드 하늘색은 선택과 정보 강조에 제한했다. 화면 전체가 파랗게 보이지 않으면서도 회사 화면과의 연결감을 유지하기 위해서다.
- 사용 가능성이 높은 작은 글씨 화면의 기존 시트 폭 조정을 보존했다. 큰 글씨 화면을 포함한 density 동작은 이번 시각 개편의 범위에서 제외했다.

- 기존 입력·검증·플래너 생성·수동 계획 진입 흐름은 정상 동작한다.

- 이후 기능이 추가될 때 새 컴포넌트도 동일한 2px radius, 선 중심 구획, 차콜 실행 버튼 원칙을 적용한다.
