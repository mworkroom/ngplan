### Work Completed

- 회원별 PVP 목표를 시작값 화면에서 `2,400 / 1,500 / 700` 중 직접 선택하도록 변경했으며, 미선택 상태는 검증 오류로 처리했다.
- 선택형 찾기 표지판 `표시 없음 / 1·분홍 / 2·연두 / 3·하늘색`을 추가했다. 회원 카드와 수동 계획표 헤더에 번호와 색상을 표시하되 계산에는 전달하지 않는다.
- PVP 목표 700 회원에게만 같은 총 PV 안에서 약 8일의 커미션 발생을 권장하도록 RuleSet과 계산 엔진을 `2.0.0`으로 갱신했다. 권장 미달은 실패가 아니며 이를 위해 PV를 추가하지 않는 기존 소프트 제약을 유지했다.
- 수동 계획표의 PVP·좌·우 열 머리글 아래에 해당 회원의 시작값을 표시하고, 보름 요약에 직접 선택한 PVP 목표를 표시했다.

- 설정을 수정해 다시 검증한 경우 안정적인 회원 키·날짜·입력 방향이 같은 칸만 이전 문자열을 유지하고, 새 칸은 기본값으로 만들며 사라진 칸은 버리도록 계획표 초안 조정 함수를 추가했다.
- `초기화`를 확정하면 설정과 수동 계획표 임시 저장을 함께 비우도록 했다.
- 조직 그림에 `− 작게`, `100%`, `+ 크게`, `화면에 맞추기` 버튼과 현재 배율 표시를 추가했다. 배율은 25%에서 150% 사이로 제한하고 현재 탭에 함께 저장한다.
- 화면 왕복·재마운트 복원, 잘못된 저장 데이터 무시, 계획표 칸 조정과 확대 버튼을 검증하는 테스트를 추가했다.
- Phase 3 실행 계획과 기술 설계에서 이 기능이 Phase 6의 영구 프로젝트 저장이 아니라 현재 탭 작업 하나만 보호하는 예외임을 명시했다.

### Decisions

- 사용자가 별도 저장·복구 개념을 배울 필요가 없도록 입력할 때 자동 저장하고 앱 시작 시 자동 복원한다.
- `sessionStorage`만 사용해 다른 탭·다른 기기·탭을 닫은 뒤의 복구는 제공하지 않는다. 프로젝트 목록, 리비전, 동기화와 장기 보관은 Phase 6 범위로 유지한다.
- 설정 수정 전의 수동 값을 무조건 복사하지 않는다. 회원·날짜가 같고 새 조직 구조에서도 직접 입력 가능한 필드에만 값을 이어 붙여 조직 합계와 직접 입력값이 섞이는 것을 막는다.
- 마우스 휠 확대는 스크롤 오작동 위험이 있어 제외하고, 항상 보이는 버튼으로만 배율을 바꾼다.

### Current Status

- 설정 화면 왕복과 앱 재마운트 뒤에도 수동 입력값이 유지되는 것을 자동 통합 테스트로 확인했다.
- 전체 377개 테스트, 타입 검사, 프로덕션 빌드와 배포 산출물 검사가 통과했다.
- 인앱 브라우저의 로컬 개발 서버 연결이 안정적으로 유지되지 않아 이번 확대 UI의 최종 육안 확인은 자동 DOM 테스트로 대체했다.

### Next Steps

- 실제 10~20명 및 50명 조직에서 `화면에 맞추기`의 최소 25% 배율과 카드 가독성이 적절한지 확인한다.
- 탭을 닫은 뒤에도 복구하거나 여러 기기에서 사용해야 할 시점에 Phase 6 저장 정책을 별도로 구현한다.
