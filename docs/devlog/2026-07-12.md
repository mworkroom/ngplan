## 추가 작업 — 계산용 레벨 제거와 찾기 표지판 도입

기존 엑셀의 `1·2·3`과 셀 색상은 조직 깊이나 PVP 목표를 뜻하는 레벨이 아니라, 넓은 시트에서 일부 회원을 빨리 찾기 위한 수동 표지판이었다는 운영 규칙을 반영했다. 계산용 레벨을 제거하고 PVP 목표·조직 위치·찾기 표지판을 서로 독립된 값으로 분리했다.

- 수동 계획표의 PVP·좌·우 열 머리글 아래에 해당 회원의 시작값을 표시하고, 보름 요약에 직접 선택한 PVP 목표를 표시했다.

## 추가 작업 — 회원 상세 화면 공간 재배치

### Work Summary

조직도가 넓게 보이도록 회원 상세 영역을 줄이고, 위치 변경·회원 처리·시작값 영역을 한눈에 구분할 수 있게 재배치했다.

### Work Completed

- 넓은 화면에서 조직도와 회원 상세의 너비를 약 75% 대 25%로 조정하고, 중간 화면에서는 입력 칸을 사용할 수 있는 최소 너비를 유지했다.
- `위치 바꾸기`를 2단계 제목으로 바꾸고 위쪽 구분선을 추가했다.
- 상위 회원, 위치, 이동 버튼을 한 줄에 배치하고 실제 회원이 아닌 빈 `위 회원 선택` 항목을 제거했다.
- `보관함에 넣기`와 `삭제하기`를 한 줄에 복구했으며, 삭제는 기존 확인 절차를 그대로 사용한다.

- 현재 화면 문구와 달라져 있던 UI 테스트 기대값을 함께 정리했으며 전체 368개 테스트를 통과했다.

### Decisions

- 회원 상세 영역은 단순히 절반 수치로 고정하지 않고, 넓은 화면에서는 전체 작업 공간의 약 25%만 사용하도록 했다. 입력 가능성을 위해 최소 320px은 유지한다.
- `위 회원 선택`은 특별한 동작이 있는 기능이 아니라 선택되지 않은 상태를 나타내던 빈 옵션이므로 제거했다.

### Current Status
