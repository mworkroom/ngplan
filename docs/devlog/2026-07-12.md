## Decisions

- 화면이나 애플리케이션 선택자에서 계산식을 다시 만들지 않고, 유효한 편집마다 Phase 1의 `calculatePlan` 결과 전체를 교체하도록 했다. 입력이 유효하지 않거나 엔진이 실패하면 부분 결과나 오래된 결과를 유지하지 않는다.
- 빈 편집값만 Phase 3 경계에서 0으로 정규화하고, 부호·지수·공백·소수·안전 범위 밖 정수는 정확한 입력 위치의 오류로 처리했다.
- 충돌 가능한 문자열 연결 대신 JSON 튜플을 인코딩해 셀 키와 DOM ID를 만들었다. 표시 문구에는 내부 회원 키를 노출하지 않는다.
- 회사 회원 ID는 Phase 3에서 재검증하거나 가공하지 않는 불투명 표시값으로 유지했다.
- 일요일 결과도 키보드로 감사할 수 있도록 별도 날짜 선택 컨트롤과 포커스 가능한 날짜 앵커를 제공했다.
