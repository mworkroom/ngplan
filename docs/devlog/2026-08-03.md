# 2026-08-03 ngplan 개발 로그

## Work Summary - 빨강 재계산 표시와 보라 메모 표시 분리

기존 빨간 표시가 향후 자동 재계산 시작점을 뜻하도록 설계됐지만, 실제 사용자는 나중에 기억할 칸에도 같은 표시를 사용하고 있었습니다. 재계산용 표시와 단순 메모를 구분할 수 있도록 우클릭 메뉴에 보라색 메모 표시를 추가했습니다.

## Work Completed - 빨강 재계산 표시와 보라 메모 표시 분리

- 우클릭 메뉴 문구를 `다시 계산할 곳`, `나중에 확인할 곳`, `표시 지우기`로 변경했습니다.
- 빨간색은 기존처럼 위·아래 실선으로 표시하고, 보라색 메모는 셀 안쪽 점선 테두리로 표시했습니다.
- 날짜와 회원이 같은 영역에서는 빨강과 보라 중 하나만 저장되며, 다른 표시를 누르면 이전 표시가 자동으로 교체되도록 했습니다.
- 보라 표시도 PVP·좌·우 세 칸에 동시에 적용되도록 기존 선택 단위를 유지했습니다.
- 보라 표시를 로컬 세션과 클라우드 계획 문서에 저장하고, 계획을 다시 열거나 자동 계산값을 적용해도 보존하도록 했습니다.
- 이미지 출력에도 보라 점선 표시가 남도록 순수 SVG 출력기를 확장했습니다.
- 입력하지 않는 날에는 기존처럼 표시 메뉴를 사용할 수 없도록 유지했습니다.
- 표시의 생성·상호 교체·삭제, 저장·복원, 자동 계획 적용, 이미지 출력을 회귀 테스트에 추가했습니다.

## Decisions - 빨강 재계산 표시와 보라 메모 표시 분리

색 이름만 보여 주면 사용자가 의미를 다시 기억해야 하므로 메뉴에는 색 대신 행동의 목적을 적었습니다. 기존 `actualDifferenceMarkers`는 향후 자동 재계산 시작점으로 사용할 빨간 표시이므로 그대로 유지하고, 보라는 계산과 무관한 `reminderMarkers`로 별도 저장했습니다. 같은 영역에 두 의미가 겹치면 재계산 기준이 모호해지므로 데이터 단계에서 상호 배타적으로 처리했습니다. 수당 발생 색 선은 셀 왼쪽에 있으므로 보라는 셀 안쪽 점선 테두리를 사용해 겹침을 줄였습니다.

## Current Status - 빨강 재계산 표시와 보라 메모 표시 분리

실제 브라우저에서 수당 300 표시가 있는 회원·날짜를 우클릭해 빨강으로 표시한 뒤 보라로 교체하고 다시 지우는 흐름을 확인했습니다. 세 칸이 함께 바뀌었고 보라 상태에서 빨간 데이터는 제거됐으며, 표시를 지운 뒤에도 수당의 왼쪽 색 선은 유지됐습니다. 브라우저 경고와 오류는 없었습니다. 집중 테스트 7개 파일의 69개 테스트, 전체 62개 파일의 729개 테스트와 커버리지 기준, TypeScript 검사, 프로덕션 빌드를 통과했습니다.

## Next Steps - 빨강 재계산 표시와 보라 메모 표시 분리

- 향후 자동 재계산 기능은 빨간 `actualDifferenceMarkers`만 시작점으로 사용하고 보라 `reminderMarkers`는 계산에서 제외합니다.
